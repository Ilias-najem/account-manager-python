# Account Manager

A simple command-line banking simulation written in Python.

## Features

- Initialize an account with a customer name and balance.
- Deposit money.
- Withdraw money if sufficient funds are available.
- Display the final balance when logging out.

## Requirements

- Python 3.x

## Usage

```bash
python3 account_manager.py
```

## Limitations

- Account data is not saved between sessions.
- Transactions are not recorded.
- Input validation is limited.
